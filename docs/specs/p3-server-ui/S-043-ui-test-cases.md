# S-043 · UI: test cases list & suite tree

**Phase:** P3 · **Depends on:** S-039, S-033 · **Packages:** `apps/web` · **Plan refs:** §8.1 Suite tree + case list
**UI:** wireframe [`docs/wireframes/03-test-cases.html`](../../wireframes/03-test-cases.html) · design.md §5 row 03

## Goal
Browse, filter, select and bulk-act on test cases organised in suites.

## Scope
- Route `/p/:key/cases?suite=&q=&page=`.
- Header actions: Import (disabled until S-062, tooltip), Generate from story · S2 (disabled until S-061 / when no S2), Record in browser (disabled until S-060), **New test case** → creates draft in current suite and opens editor.
- `SuiteTree` aside: All cases + nested suites with ▸/▾ and counts, "+" add suite (inline input), rename/delete via context menu (Radix DropdownMenu); "Library": Shared steps & flows, Test data sets, Requirements (simple list pages reusing table pattern).
- List card: `QueryInput` "Filter" bound to `q` (debounced), dropdown buttons Priority / Last result / Owner / Status that append query terms; selection bar "N selected · Add to plan · Move · Tag · Run now" (Add to plan disabled until S-049); git sync tag "Synced with .s1pilot/ in git · clean" from `syncStatus`.
- Table: checkbox, Key (mono), Title link + tags line (13 px muted, or "generated by S2 · needs review"), Priority, Learned script (`Ready · staging` / `Healed · needs approval` / `Not learned yet` / `—`), Last result `StatusPill`, Owner. Selected rows `--surface-selected`.
- Pagination "Showing x of n · Page 1 of n".
- Run now (bulk) → run launcher dialog (env, browser, mode) → `runs.create` → navigate to live run.

## Acceptance criteria
- [ ] Filter in URL is shareable; back/forward restore state.
- [ ] Bulk Move/Tag work for multi-select; keyboard ↑/↓/space selection.
- [ ] Table scrolls horizontally within card at narrow widths.

## Tests
- Component + e2e with seeded cases.

## Out of scope
- Case editor (S-044).
